### Transformer Decoder 总览

Decoder 负责自回归地（逐词）生成序列，它在每一步都依赖于已生成的历史信息和来自 Encoder 的全局上下文。
```
Input: <start>, token_1, token_2, ..., token_{t-1}
           ↓
Input Embedding + Positional Encoding (RoPE)
           ↓
Layer 1:   ┌──────────────────────────────────────────┐
           │  Masked Multi-Head Self-Attention        │
           │  (只能看左边，理解已生成的上下文)             │
           └──────────────────────────────────────────┘
                          ↓
           ┌··········································┐
           :  Multi-Head Cross-Attention              :
           :  (⚠️ 仅传统架构存在，现代 LLM 已移除此层)    :
           └··········································┘
                          ↓
           ┌──────────────────────────────────────────┐
           │  Feed-Forward Network (SwiGLU)           │
           │  (深度思考，特征提取)                      │
           └──────────────────────────────────────────┘
           ↓
    ... (N 层重复)
           ↓
Layer N:   同上
           ↓
Final RMSNorm
           ↓
Linear + Softmax → 预测下一个 token 的概率分布
```

### ⚙️ 一、Decoder 单层完整结构现代 SOTA (Pre-LN)

现代 Transformer（如 LLaMA、GPT 系列的 Decoder-only 结构）普遍采用 Pre-LN 结构，以确保深层网络的梯度稳定。

> - 标准 Decoder（翻译任务/T5/Bart）：包含 3 个子层（Masked Self-Attn + Cross-Attn + FFN）。依靠 Cross-Attention 引入 Encoder 的信息。
> - 主流 LLM（GPT/LLaMA/DeepSeek）：采用 Decoder-Only 架构。它们移除了 Cross-Attention 层，只保留 Masked Self-Attn + FFN。所有的输入（Prompt）和输出都拼接在同一个序列中处理。



现代主流（Pre-LN）Decoder 层结构 
|步骤|子模块核心作用|Pre-LN 公式（现代推荐）|
|---|---|---|
|1|Masked Self-Attention理解已生成的上下文| $x_1 = x + \text{MaskedMHA}(\text{LayerNorm}(x))$ |
|2|Cross-Attention连接 Encoder，从原文中汲取信息|$x_2 = x_1 + \text{CrossAttention}(\text{LayerNorm}(x_1), \text{EncoderOutput})$|
|3|FFN对融合信息进行深度非线性加工|$x_3 = x_2 + \text{FFN}(\text{LayerNorm}(x_2))$|


关键原理： 在 Pre-LN 结构中，残差连接 $x + \text{Sublayer}(\dots)$ 路径的导数始终为 1，保证了梯度不会消失。同时，$\text{LayerNorm}$ 先作用于 $x$，确保进入注意力子层的输入始终是规范化和稳定的，从而避免了深层网络中的梯度爆炸。

>tips: $$
x_2 =x_1 + \text{CrossAttention}(Q=\text{LayerNorm}(x_1),K=\text{EncoderOutput},V=\text{EncoderOutput}) $$

伪代码
```python
class DecoderLayer(nn.Module):
    def forward(self, x, encoder_out=None):
        # 1. 自注意力（带 Mask，看自己之前的历史）
        # distinct: causal mask used here
        x = x + self.masked_mha(self.ln1(x), is_causal=True)
        
        # 2. 交叉注意力（可选，仅 Encoder-Decoder 架构需要）
        if encoder_out is not None:
            x = x + self.cross_mha(self.ln2(x), context=encoder_out)
            
        # 3. 前馈网络（SwiGLU）
        x = x + self.ffn(self.ln3(x))
        return x
```

### 🧠 二、Decoder 每一部分到底在算什么？

1. Masked Multi-Head Self-Attention（自注意力，带遮盖）

目标：让当前位置 $i$ 的 token 只能关注到位置 $j \le i$ 的信息，实现单向自回归。

- 计算过程：
    - $Q, K, V$ 全部来自上一层 Decoder 的输出 $X_{\text{decoder}}$（或第一层时的输入嵌入）。
    - 核心区别： 在计算注意力分数
$\text{softmax}( \frac{QK^T}{\sqrt{d_k}} + \text{mask} )$ 时，下三角矩阵的 mask 被应用。

    $$\text{Attention}(Q,K,V) = \text{softmax}\left( \frac{QK^T}{\sqrt{d_k}} + \textbf{Mask} \right) @ V$$

    - Mask 细节：Mask 矩阵是一个 $\text{seq\_len} \times \text{seq\_len}$ 的上三角矩阵。未来位置（$j > i$）被置为 $\mathbf{-\infty}$。
    - Why $-\infty$：只有 $-\infty$ 能确保 $\text{softmax}(-\infty) = 0$，使得未来位置的注意力权重严格为 $0$，从而在数值上可靠地隔离了信息

- 输出： $x_1$ 包含了对已生成部分的上下文理解。


- Pre-LN 数据流：$$x_1 = x + \text{MaskedMHA}(\text{LayerNorm}(x))$$
    - $x$ 是当前层的输入（上一层输出）。
    - $x_1$ 是第一步 MHA 加工后的输出，包含了已生成部分的上下文理解。


2. Multi-Head Cross-Attention（交叉注意力，连接 Encoder）

目标：让 Decoder 查询（Query）Encoder 提供的源语言上下文（Key, Value），找到最相关的部分进行信息修正。

- 计算过程：
    - $Q$ (查询 Query)：来自Masked MHA 的输出 $x_1$。这代表`我现在想知道什么`。
    - $K, V$ (键 Key, 值 Value)：来自 Encoder 的最终输出 $\text{EncoderOutput}$。这代表`源文本有什么信息`。
    - 维度对齐：
        - $Q$ 形状：$(B, \mathbf{T_{tgt}}, d_{\text{model}})$
        - $K, V$ 形状：$(B, \mathbf{T_{src}}, d_{\text{model}})$
        - $T_{\text{tgt}}$（目标序列长度）和 $T_{\text{src}}$（源序列长度）通常不相等。交叉注意力机制完美处理了这种长度差异。

    - 实现细节：$\mathbf{EncoderOutput}$ 矩阵通常被称为Memory，它在模型初始化时只计算一次，并在每一层 Decoder 中被重复使用（复制 $N$ 份）作为 $K, V$。
    - 输出： $x_2$ 是融合了目标上下文和源上下文的表示。残差连接保证了 $x_2$ 是对 $x_1$ 的有效增强，而不是推翻重写。

3. Feed-Forward Network（FFN）

目标： 对融合了所有信息的 $x_2$ 进行深度的非线性变换和特征抽象。

- 现代结构（SOTA）： 采用 SwiGLU 激活函数（如 LLaMA、Grok），替代传统的 GELU。
    -  公式： $$ SwiGLU(x)=(xW_1)⊗Swish(xW_3)⋅W_2$$
        -  其中 $Swish(x)=x⋅σ(x)$，$⊗$ 是逐元素乘法。
    - SwiGLU：涉及 $3$ 个线性层 $W_1, W_2, W_3$，而非传统的 $2$ 个线性层。参数效率：
    - SwiGLU 通常将维度膨胀系数设为 $\sim 8/3$ 或更小，相比传统 FFN 的 $4$ 倍膨胀，以更少的参数量 (约 $6d_{\text{model}}^2$ vs. $8d_{\text{model}}^2$) 达到更优效果。

        -  传统 FFN（GELU）：标准 FFN：$d\to4d\to d$。参数量 $\approx8d^2$
        - SwiGLU：$d\to 8/3d\to 8/3d\to d$。参数量 $\approx 6d^2$
        - 由于有 3 个权重矩阵，通常将中间维度缩小为原来的 $2/3$，即 $4d\times2/3\approx2.67d$。
        - 结论：在参数量几乎不变的情况下，SwiGLU 利用门控机制提供了更强的非线性表达能力。
    - SwiGLU 通常将中间维度设为 $8/3d_{\text{model}}$，总参数量约 $5.33d_{\text{model}}^2$，低于传统 FFN 的 $8d_{\text{model}}^2$，实现更高参数效率。


- 输出： $x_3$ 是该 Decoder 层的最终输出，作为下一层的输入。


### 🎯 三、Decoder 的最终输出与自回归生成


1. 核心工程优化：

    在自回归推理时，生成第$t$个 token 时，之前的$t-1$ 个token 的 $K$ & $V$ 矩阵已经计算过了,我们不需要每一步都重算整个序列，而是将之前的$K$ $V$ 缓存下来，每一步只计算最新一个 token 的 $Q$ $K$ $V$，然后把新的$K$ $V$ 与缓存的$K$ $V$ 合并，再进行注意力计算。
    
    - 优势：将推理的时间复杂度从$O(T_{tgt}^2)$降低到$O(T_{tgt})$
    - 缺点：显存占用增加（显存换速度）。

    **进阶**：从 MHA 到 GQA (Grouped Query Attention)
    - 为了缓解 KV Cache 带来的巨大显存压力（这是推理长文本的瓶颈），现代 LLM（如 LLaMA-3, DeepSeek）普遍采用 GQA。
    - MHA (标准)：每个 Query Head 都有自己独立的 K, V Head。（显存占用大）
    - MQA (极致)：所有 Query Head 共享同一组 K, V Head。（效果有损失）
    - GQA (折中 SOTA)：将 Query 分组，每组共享一对 K, V。例如 32 个 Q 配对 4 个 K, V。
    - 效果：KV Cache 显存降低 8-32 倍，推理速度大幅提升，且精度几乎不掉。

2. 最终输出
    - Decoder 最后一层的输出 $Z$ 先经过一个最终的 LayerNorm。
    - 线性投影层：将 $Z$ 投影到词汇表大小 $V_{\text{vocab}}$ 的维度上（Logits）。
    - Softmax 层：将 Logits 转换为概率分布 $P$，预测下一个 token。


3. 训练与推理机制
    | 阶段 | 机制 | 描述 |Mask|
    | --- | --- | --- |---|
    | 训练 (Training) | Teacher Forcing | Decoder 的输入是真实的目标序列（右移一位），模型以并行方式计算所有位置的损失。这加速了模型收敛，防止模型过早陷入错误。 |使用下三角Mask|
    | 推理 (Inference) | 自回归生成 | 模型从 $\langle \text{start} \rangle$ token 开始，逐词生成。每一步的预测结果会被作为下一步的输入。 |每步动态生成 Mask|
    | 推理优化 | Beam Search | 简要提及 Beam Search/Top-K/Top-P 等采样策略，用于代替简单的 greedy search，保留 $\text{top-}k$ 个概率最高的候选序列，以生成质量更高的句子。 |

### 🔄 四、核心区别总结：
Encoder vs. Decoder

| 特征 | Encoder | Decoder（训练时） |Decoder (推理时)|
| --- | --- | --- |---|
| 主要功能 | 上下文编码：将源序列转换为语境化的特征向量。 | 序列生成：逐词生成目标序列。 |
| 信息流向 | 双向：每个 token 看到所有 token。 | 单向：每个 token 只看到自己和之前已生成的 token。 |
| 关键注意力 | Self-Attention | Masked Self-Attention 和 Cross-Attention |
|位置编码|绝对位置或 RoPE|必须具备外推性（RoPE 是首选）|
|注意力矩阵|全 1 矩阵（看到所有）|下三角矩阵（Causal Mask，只能看左边|
|KV cache|不需要|推理时必需（否则速度极慢）|
| Mask 应用 | 无（全连接） | 有（Self-Attention 必须有下三角 Mask） |
| 训练模式 | 并行处理整个序列。 | 并行（Teacher Forcing），但要计算单向 Mask。 |
| 输出用途 | 作为 Decoder 的 K,V（记忆 Memory）。 | 作为 预测下一个 token 的 Logits。|
|是否可并行|可以（双向，无 mask）|可以（Teacher Forcing + Causal Mask）|不行，必须逐字生成|
|信息流向|双向（bidirectional）|单向（causal / autoregressive|单向（causal）|
|是否需要 Mask|不需要|需要下三角mask|需要下三角mask|
