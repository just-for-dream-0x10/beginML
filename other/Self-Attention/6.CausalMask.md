### 下三角 Mask（Causal Mask）详解：Transformer Decoder 的`时间机器锁`

在 Transformer Decoder 的 Masked Self-Attention 中，**下三角 Mask**（也叫 Causal Mask 或 Future Mask）是确保模型**自回归生成**（autoregressive）的关键机制。它像一个`时间锁`，防止当前 token `偷看`未来的 token，从而模拟真实生成过程（一个词一个词地产生）。


---

#### 1. **什么是下三角 Mask？（定义与目的）**

- **定义**：下三角 Mask 是一个布尔或数值矩阵，用于在注意力计算中`屏蔽`未来位置的信息。它是一个 **seq_len × seq_len** 的矩阵（seq_len 是序列长度），其中：
  - **下三角部分**（包括对角线）：值为 0 或 True（允许关注）。
  - **上三角部分**（未来位置）：值为 -∞ 或 False（禁止关注）。

- **目的**：
  - **确保因果性（Causality）**：在生成序列时，第 i 个位置的 token 只能看到第 1 到 i 个位置的信息，不能看到 i+1 之后的`未来`信息。
  - **模拟自回归**：像人类写作一样，先写前面的词，再基于前文决定后面的词。避免模型在训练时“作弊”看到整个目标序列。
  - **为什么叫`下三角`**？因为在矩阵中，允许的部分是下三角（从左上到右下），禁止的部分是上三角（未来）。

**直观类比**：想象你在写日记，第 5 句话不能提前知道第 6 句话的内容。Mask 就是“蒙眼布”，让你只看到已写好的部分。

---

#### 2. **下三角 Mask 的矩阵形式（示例）**

假设序列长度 seq_len = 4（例如，输入序列：[BOS, token1, token2, token3]）。

- **Mask 矩阵**（数值形式，用于注意力分数加法）：
  ```
  Row (Query) \ Col (Key) | 位置 0 (BOS) | 位置 1 (token1) | 位置 2 (token2) | 位置 3 (token3)
  -----------------------|--------------|-----------------|-----------------|-----------------
  位置 0 (BOS)           |      0       |      -∞         |      -∞         |      -∞
  位置 1 (token1)        |      0       |       0         |      -∞         |      -∞
  位置 2 (token2)        |      0       |       0         |       0         |      -∞
  位置 3 (token3)        |      0       |       0         |       0         |       0
  ```
  - **解释**：
    - 行（Query）：当前 token 在`问`谁的信息。
    - 列（Key）：可被关注的 token。
    - 对于第 i 行（第 i 个 token），它只能看到第 0 到 i 列（0 表示允许，-∞ 表示禁止）。
    - 对角线（i == j）是 0，允许 token 关注自己。

- **布尔形式**（用于 PyTorch 等框架的 attn_mask 参数）：
  ```
  [[ True, False, False, False],
   [ True,  True, False, False],
   [ True,  True,  True, False],
   [ True,  True,  True,  True]]
  ```
  - True：允许关注；False：禁止关注。

**关键**：Mask 是**上三角为 -∞/False**（未来），**下三角为 0/True**（过去和现在）。这确保了“因果顺序”。

#### 3. **下三角 Mask 在注意力计算中的作用（数学公式）**

在 Multi-Head Self-Attention 中，注意力分数计算公式是：
$$
\text{Attention Scores} = \frac{Q K^T}{\sqrt{d_k}}
$$
然后加上 Mask：
$$
\text{Masked Scores} = \frac{Q K^T}{\sqrt{d_k}} + \text{Mask}
$$
最后：
$$
\text{Attention}(Q, K, V) = \text{softmax}(\text{Masked Scores}) \cdot V
$$

- **为什么加 Mask？**
  - 未加 Mask：第 i 个 token 会计算所有位置的注意力分数，包括未来，导致 softmax 后未来位置有非零权重（模型“看到”未来）。
  - 加 Mask：未来位置的分数变成 -∞，softmax(-∞) = 0，确保权重严格为 0。
  - **数值稳定性**：用 -∞ 而非一个大负数（如 -1e9），因为 softmax 会将任何有限负数映射到接近 0 但非严格 0 的值，可能导致微弱泄漏。

**示例计算**（seq_len=3，简化）：
- 原始 Scores（假设）：
  ```
  [[ 2.0, 1.5, 3.0 ],  # token0 的分数
   [ 1.0, 2.5, 0.5 ],  # token1 的分数
   [ 0.5, 1.0, 2.0 ]]  # token2 的分数
  ```
- 加 Mask 后（Mask 如上例）：
  ```
  [[ 2.0, -∞, -∞  ],  # token0 只看自己
   [ 1.0, 2.5, -∞  ],  # token1 看 0 和 1
   [ 0.5, 1.0, 2.0 ]]  # token2 看 0、1、2
  ```
- softmax 后：未来列权重 = 0，注意力只集中在过去和现在。

#### 4. **代码实现（PyTorch 示例）**

在 PyTorch 的 `nn.MultiheadAttention` 中，`attn_mask` 参数接收布尔或数值 Mask。

```python
import torch
import torch.nn.functional as F

def create_causal_mask(seq_len, device='cpu'):
    # 生成上三角 -∞ 的 Mask（下三角为 0）
    mask = torch.triu(torch.ones(seq_len, seq_len, device=device) * float('-inf'), diagonal=1)
    return mask

# 示例：seq_len=4
seq_len = 4
mask = create_causal_mask(seq_len)
print(mask)
# 输出：
# tensor([[  0., -inf, -inf, -inf],
#         [  0.,   0., -inf, -inf],
#         [  0.,   0.,   0., -inf],
#         [  0.,   0.,   0.,   0.]])

# 在注意力中使用（简化版 Scaled Dot-Product Attention）
def masked_attention(Q, K, V, mask):
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (K.size(-1) ** 0.5)
    scores = scores + mask.unsqueeze(0).unsqueeze(0)  # 广播到 batch 和 head 维度
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output

# 假设 Q, K, V 形状: (batch, seq_len, d_k)
# output = masked_attention(Q, K, V, mask)
```

- **注意**：
  - `torch.triu(..., diagonal=1)`：从对角线以上（上三角）开始填充 -∞，对角线和以下为 0。
  - 在实际模型中，Mask 会根据 batch_size 和 num_heads 广播（unsqueeze）。

#### 5. **为什么是下三角？（原理与必要性）**

- **因果自回归的核心**：Transformer Decoder 是为序列生成设计的（如翻译、聊天）。生成时，必须严格遵守“过去 → 现在 → 未来”的顺序：
  - token1 生成时，只能看 BOS。
  - token2 生成时，看 BOS + token1。
  - ...以此类推。
- **如果不用 Mask**：
  - 模型会变成“双向”（像 Encoder），看到整个序列，导致训练时“作弊”，推理时无法自回归（因为不知道未来词）。
- **上三角 vs 下三角**：
  - **下三角 Mask**（允许下三角）：标准 Causal Mask，用于自回归（从左到右生成）。
  - **上三角 Mask**：很少用，通常在某些变体中用于反向生成（从右到左），但不常见。
- **在 Encoder 中**：不需要 Mask，因为 Encoder 是双向的（全序列并行处理）。

**实验验证**：如果去掉 Mask，Decoder 在翻译任务中会崩溃——生成的句子会乱序或无意义，因为模型提前“知道”了答案。

#### 6. **常见误区与澄清**

- **误区1**：Mask 是加在 V 上？  
  **错**：Mask 加在注意力分数（QK^T）上，不是 V。目的是屏蔽分数计算，不是屏蔽值。

- **误区2**：Mask 只用于推理？  
  **错**：训练和推理都用！训练时用 Teacher Forcing + Mask 实现并行；推理时用 Mask 确保自回归。

- **误区3**：-∞ 会导致 NaN？  
  **对**：在浮点计算中，softmax(-∞) = 0，不会 NaN。但要确保框架支持（如 PyTorch）。

- **误区4**：Decoder 的 Cross-Attention 也需要 Mask？  
  **错**：不需要！Cross-Attention 的 K/V 来自 Encoder（已知的全序列），Q 来自 Decoder（已生成部分），所以是“自由查看” Encoder 的所有信息。

---

#### 7. **一句话总结**

下三角 Mask 就是一个 **seq_len × seq_len 的上三角 -∞ 矩阵**，加在注意力分数上，确保 softmax 后未来位置权重严格为 0，从而强制 Decoder 遵守因果顺序，实现真正的自回归生成。
