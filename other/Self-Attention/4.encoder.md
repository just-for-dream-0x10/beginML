### Transformer Encoder 总览（一图秒懂）

```
Input Embedding + Positional Encoding
           ↓
Layer 1:   ┌───────────────────────┐
           │  Multi-Head Self-Attention │ → 残差 + LayerNorm
           │  Feed-Forward Network      │ → 残差 + LayerNorm
           └───────────────────────┘
           ↓
Layer 2:   同上结构
           ↓
    ...   
           ↓
Layer N:   同上（通常 N=6 或 12）
           ↓
Encoder 最终输出：每个 token 的最终 contextual representation
```

这就是 Encoder 的全部！下面我们逐层拆开讲细节。

---

### 一、Encoder 单层完整结构

现在主流实现（包括谷歌、OpenAI、Meta、DeepSeek 等）基本都用 **Pre-LN + GELU/SwiGLU**，结构如下：

```python
class TransformerEncoderLayer(nn.Module):
    def forward(self, x):
        # 1. Pre-LN 自注意力分支
        x = x + self.mha( self.ln1(x) )          # Pre-LN 版
        # 2. Pre-LN 前馈分支  
        x = x + self.ffn( self.ln2(x) )          # Pre-LN 版
        return x
```

**原始论文（Post-LN）** 和 **现代推荐（Pre-LN）** 都列出来对比：

| 版本       | 原始 Transformer (2017) Post-LN                  | 现代主流推荐 (2024) Pre-LN + GELU/SwiGLU      |
|------------|--------------------------------------------------|-----------------------------------------------|
| 自注意力   | x1 = LayerNorm(x + MHA(x))                       | x1 = x + MHA(LayerNorm(x))                    |
| 前馈网络   | output = LayerNorm(x1 + FFN(x1))                 | output = x1 + FFN(LayerNorm(x1))              |
| 激活函数   | ReLU                                             | GELU 或 SwiGLU（LLaMA、PaLM、Grok 都在用）    |
| 训练稳定性 | 深层时容易梯度爆炸                               | 极度稳定，可轻松训 100+ 层                    |

现在的 LLaMA、Grok 等模型实际使用的是 `RMSNorm`。它去掉了 `LayerNorm`中的均值（Mean）计算，只保留方差缩放，计算更快且效果相当。


### 二、Encoder 每一部分到底在算什么？

#### 1. Input Embedding + Positional Encoding（输入阶段）

- Word Embedding：维度通常 512、768、1024、1280、2048 等
- 位置编码有三种主流做法（任选其一）：
  1. 原始论文：Sinusoidal 位置编码（不学）
  2. Learnable：BERT 使用，可学习的绝对位置 embedding。
  3. RoPE (旋转位置编码)：当前 SOTA 标准。虽然主要用于 LLaMA 等 Decoder 模型，但现代 Encoder 架构（如 GLM）也开始采用。它通过旋转向量角度注入位置信息，外推性极强。

#### 2. Multi-Head Self-Attention（核心中的核心）

这是 Encoder 最最最最最最重要的部分。

一个 token 最终能`看到`整条序列的所有信息，全靠它。

计算过程（以第 l 层为例）：

$$
\text{Attention}(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}}+Mask)V
$$

- $\sqrt{d_k}$：防止点积太大，softmax 梯度消失
- $Mask$：Padding Mask,Encoder 是双向的，可以看到全文，但必须 Mask 掉 <pad> 占位符，防止模型关注无意义填充。
- `FlashAttention`： 工程必备。PyTorch 2.0+ 内置。它不改变数学计算量（仍是 $O(N^2)$），但通过分块计算（Tiling）和减少 GPU HBM 读写（IO-Awareness），实现 3-5 倍加速并大幅节省显存。


#### 3. Feed-Forward Network（FFN）

负责对特征进行深度的非线性变换。

两层线性 + 激活，膨胀系数通常是 4

```python
# 1. 经典写法 (BERT/GPT): d -> 4d -> d
hidden = GELU(x @ W1 + b1)
output = hidden @ W2 + b2

# 2. 现代写法 (SwiGLU - LLaMA/DeepSeek): 
# 注意：为了保持参数量恒定，中间维度通常缩减为原来的 2/3
# d_ff = 2/3 * 4 * d_model
x_gate = Swish(x @ W_gate)
x_val  = x @ W_in
output = (x_gate * x_val) @ W_out  # 逐元素相乘
```

当前 SOTA 结论：**SwiGLU > GELU > ReLU**

### 三、Encoder 最终输出了什么？

经过 N 层 Encoder 后，得到一个形状为 **(batch_size, seq_len, d_model)** 的矩阵。

这个矩阵的每一行，就是当前 token 融合了**整条序列全部信息**之后的最终上下文表示。

如何使用这个输出？
- 序列标注（分词/NER）：对每个 Token 的向量单独分类
- 整句分类（如情感分析）：
  - BERT 做法：取第一个 token ([CLS]) 的向量作为整句表示。
  - Mean Pooling：把所有 token 的向量取平均。

举例（以中文为例）：

输入： 我 爱 吃 苹 果
第 6 层 Encoder 输出中，`我`这一行的向量，已经包含了`我爱吃苹果`整句话的所有信息，知道自己是主语，知道后面要表达爱吃苹果的情感。

这就是上下文建模的全部意义。

### 五、一句话总结 Encoder 的工作原理

**Encoder 的每一层都在干同一件事：**

- **全局咨询 (Self-Attention)**：拿着自己的问题去问句子里所有人，聚合信息。
- **深度反思 (FFN)**：把问到的信息结合自己的理解，进行非线性加工。
- **最终目标**：把`含糊的字面输入`变成`包含丰富上下文的语义理解`。
